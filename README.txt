# Digma Optima 8 Z801 4G (TS8194ML) — Original Recovery & Firmware Files

This repository contains the original stock `recovery.img` and partition dump files extracted directly from the official firmware of the **Digma Optima 8 Z801 4G** tablet (Model: **TS8194ML**), running on the Unisoc (Spreadtrum) SC9863A chipset.

### ⚠️ IMPORTANT: Hardware Revision Compatibility
* **Target Revision:** This specific backup is strictly intended for **Revision 1 (Rev. 1)** of the tablet.
* **Warning:** Do not attempt to flash these files or use the generated device tree for Revision 2 (Rev. 2) or later hardware variants. Flashing components across mismatched hardware revisions on Unisoc devices will result in a hard brick (permanent bootloop or black screen).

### File Details
* **Device:** Digma Optima 8 Z801 4G
* **Model Number:** TS8194ML
* **SoC:** Unisoc / Spreadtrum SC9863A
* **Purpose:** These files serve as the baseline for creating a custom TWRP/OrangeFox device tree and act as a safe fallback to restore the stock recovery environment.
